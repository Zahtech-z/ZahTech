# Agent Task Completion Report

Copy and complete this template for each assigned task. Use the language required by the product team.

```text
Task / Tâche: <ticket> — <title>
Status / Statut: completed | blocked | awaiting owner
Work done / Fait: <2–5 lines>
Evidence / Preuves: <commands run and actual outcomes>
  - VERIFIED / VÉRIFIÉ: <personally executed or inspected>
  - REPORTED / RAPPORTÉ: <asserted elsewhere, not independently checked>
  - UNKNOWN / INCONNU: <not yet verified>
Files changed / Fichiers modifiés: <list>
Branch / PR: <name> / <link>
Blockers / Bloqueurs: <none or details>
Owner decision needed / Décision attendue: <none or precise question>
Proposed next step / Prochaine étape: <one line>
```

Before a sensitive action, request approval using exactly four labeled lines: Action, Scope, Risk, Expected result.
