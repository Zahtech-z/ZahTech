## Adoption

- Each product retains its own technical architecture, business rules, and launch gates.
- Agents must read the relevant product instructions before acting.
- Product-specific rules take precedence when they are more restrictive; conflicts are escalated to the human owner.
- This draft is derived from excerpts of OnzScore's agent documentation shared for review, not from a complete audit of its source files.
- No website code, existing Claude agents, or production configuration is modified by this proposal.
