# Security Baseline

**Status:** Draft

- Apply least privilege to users, services, agents, and CI credentials.
- Keep secrets out of source control, logs, screenshots, and task reports.
- Review authentication, authorization, input validation, rate limits, and trust boundaries for relevant changes.
- Treat billing, production, external accounts, schema changes, and database writes as approval-gated operations.
- Record vulnerabilities with severity, scope, remediation, and evidence of retesting.
- Do not treat a merged fix as fully validated if required security checks remain failing.
- Product-specific security controls and threat models remain in the product repository.
